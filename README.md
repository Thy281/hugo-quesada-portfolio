# Hugo Quesada Portfolio

A multilingual portfolio built with Next.js and React. It presents Hugo's data, machine learning, and application projects in a compact terminal-inspired layout.

## Features

- English, Portuguese, and Spanish content
- Dark and light themes
- Project links, tools, contact links, and LinkedIn certifications
- Responsive layout and a custom transparent favicon

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

The live portfolio is available at [hyugo.me](https://hyugo.me).
